# جدول مقارنة أكاديمي مختصر
# التطوير الأصلي و«ريأكت نيتف» و«فلاتر»

ملاحظة: عند اللصق في Word اضبط اتجاه الجدول والنص على «من اليمين إلى اليسار» (RTL).


## جدول المقارنة المتكامل

| معيار المقارنة | التطوير الأصلي (Native: Swift و Kotlin) | ريأكت نيتف (React Native) | فلاتر (Flutter) |
|----------------|------------------------------------------|----------------------------|------------------|
| الجهة المطوّرة | آبل (Apple) وجوجل (Google) لكل منصة | ميتا (Meta) | جوجل (Google) |
| لغة البرمجة | سويفت (Swift) و كوتلن (Kotlin) | جافاسكربت (JavaScript) أو تايبسكربت (TypeScript) | دارت (Dart) |
| نموذج التطوير | تطبيق مستقل لكل منصة | تطبيق متعدد المنصات بكود مشترك | تطبيق متعدد المنصات بكود مشترك |
| آلية عرض الواجهة | عناصر نظام التشغيل الأصلية | عناصر أصلية عبر جسر مع جافاسكربت | رسم ذاتي بمحرك سكيا (Skia) |
| الأداء العام | الأعلى غالباً | جيد جداً لمعظم التطبيقات | ممتاز وقريب من الأصلي |
| أداء الرسوميات المعقدة | ممتاز | جيد إلى جيد جداً | ممتاز |
| سرعة التطوير | منخفضة نسبياً | عالية | عالية |
| تكلفة التطوير والصيانة | الأعلى | منخفضة إلى متوسطة | منخفضة إلى متوسطة |
| مشاركة الكود بين أندرويد وآي أو إس | محدودة جداً | مرتفعة | مرتفعة |
| مشاركة المنطق مع الويب | ضعيفة | قوية مع منظومة ريأكت (React) | متوسطة |
| الوصول لواجهات النظام | كامل ومباشر | جيد مع وحدات أصلية عند الحاجة | جيد مع قنوات المنصة عند الحاجة |
| تناسق المظهر بين المنصات | متوسط ويختلف حسب النظام | جيد مع طابع قريب من كل نظام | مرتفع جداً |
| حجم التطبيق الابتدائي | غالباً الأصغر | متوسط | قد يكون أكبر |
| منحنى التعلم | مرتفع | متوسط لفريق جافاسكربت | متوسط مع تعلّم دارت |
| الدعم المجتمعي والرسمي | رسمي وقوي من آبل وجوجل | كبير جداً في عالم جافاسكربت | كبير ومدعوم من جوجل |
| ملاءمة النماذج الأولية والمنتجات السريعة | منخفضة | مرتفعة | مرتفعة |
| ملاءمة التطبيقات الحساسة للأداء العميق | مرتفعة جداً | متوسطة إلى مرتفعة | مرتفعة |
| الأدوات الأساسية | إكس كود (Xcode) و أندرويد ستوديو (Android Studio) | أدوات ريأكت نيتف و إكسبو (Expo) اختيارياً | أدوات فلاتر الرسمية |


## خلاصة اختيار التقنية

| إذا كان المعيار الأهم | التقنية الأنسب |
|------------------------|----------------|
| أقصى أداء وتحكم نظامي كامل | التطوير الأصلي (Swift و Kotlin) |
| سرعة التطوير مع فريق جافاسكربت ومسار ويب مشترك | ريأكت نيتف (React Native) |
| تناسق بصري عالٍ وواجهة مخصصة بين المنصات | فلاتر (Flutter) |


## استنتاج موجز لمشروع «بيان»

بما أن المشروع تطبيق تعليمي للأطفال يعتمد على التفاعل والصوت وسرعة بناء عدة شاشات وألعاب، مع إمكانية ربط لاحق بلوحة ويب، فإن «ريأكت نيتف» (React Native) مع «إكسبو» (Expo) يُعد الخيار الأنسب من حيث التوازن بين جودة التجربة وسرعة التطوير وتكلفة الصيانة.
